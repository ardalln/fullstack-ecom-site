# Iran address data

- City names: `@code-plate/iran-cities` 1.0.2, MIT, https://github.com/MJavadSF/Iran-Cities
- County names and province relations: Open Admin Data, Iran Administrative Divisions, dataset updated 2026-09-08, CC BY 4.0, https://github.com/open-admin-data/iran-administrative-divisions

The local JSON combines the city and county lists by province. The county label prefix `شهرستان` was removed for display. The data is bundled locally; address entry does not call these projects at runtime.
